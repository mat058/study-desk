# Prompt-Rezepte

Versionierte, wiederverwendbare Aufträge an KI-Agenten (Claude Code). Belegt den KI-Workflow für Kap. 4.2 und 6.

- Ein Rezept pro Datei: `NN_kurzname.md` (z. B. `01_crud-grundgeruest.md`)
- Aufbau: **Ziel · Kontext (Dateien) · Auftrag · Akzeptanzkriterien · Ergebnis/Notizen**
- Nach der Ausführung: Ergebnis + eigene Anpassungen notieren und im `docs/ai-log.md` verlinken.
