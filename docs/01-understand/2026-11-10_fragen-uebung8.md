## Teil 2 – Problemraum-Analyse

### Nutzer:innen
**2.1** Wer hat dieses Problem? (du selbst, Mitstudierende, Teilzeit-/Berufsbegleitende, Erstsemestrige, Austauschstudierende …)
- 

**2.2** Gibt es Unterschiede zwischen diesen Gruppen? (z. B. wer arbeitet nebenbei, wer hat wie viele Module)
- 

### Heutige Situation & Tools
**2.3** Welche Tools nutzt du heute, um dein Semester zu organisieren, und wofür genau?
| Tool | Wofür nutzt du es? | Was stört dich daran? |

| Moodle | | |

| Notion | | |
| (weitere: Kalender, Evento, Teams, Papier …) | | |

**2.4** Beschreib einen typischen Ablauf: Eine neue Abgabe / ein Leistungsnachweis wird angekündigt – was machst du Schritt für Schritt, bis du sie im Griff hast?
- 

**2.5** Wie viel Zeit pro Woche brauchst du ungefähr nur fürs Organisieren (suchen, übertragen, nachschauen)? Schätzung reicht.
- 

### Probleme & Herausforderungen
**2.6** Konkretes Beispiel: Wann hast du etwas fast verpasst, doppelt gesucht oder den Überblick verloren? Was ist passiert?
- 

**2.7** Was ist das Mühsamste daran, dass die Infos auf mehrere Orte verteilt sind?
- 

**2.8** Gibt es Rahmenbedingungen, die es schwieriger machen? (Job bei Belimo, Pendeln, Wechsel Mac/Handy, unterschiedliche Systeme je Dozent …)
- 

### Bedürfnisse
**2.9** Was würdest du dir wünschen? Wie sähe ein «perfekter» Semesterüberblick für dich aus? (Gefühl/Ergebnis beschreiben, noch keine Funktionen!)
- 

**2.10** Was ist dir dabei am wichtigsten? (z. B. nichts verpassen, weniger Stress, Zeitersparnis, sehen wo ich stehe)
