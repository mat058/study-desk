# Screenshot-Konvention

- **Ablage:** im Ordner der jeweiligen Phase (`docs/0X-.../`), Erweiterungen in `docs/extensions/`, GitHub/Board in `docs/organisation/`
- **Name:** `JJJJ-MM-TT_kurzbeschreibung.png`, z. B. `2026-12-02_detailseite-bearbeiten.png`
- **Vorher/Nachher:** `..._vorher.png` / `..._nachher.png` (wichtig für Verbesserungen aus der Evaluation)
- **Mac:** `Cmd+Shift+4` (Ausschnitt), `Cmd+Shift+4` + Leertaste (Fenster). Browserfenster auf ca. 1440 px Breite, für Mobile-Ansicht DevTools (iPhone-Grösse)
- **Keine echten Personendaten** auf Screenshots (Testdaten verwenden)
- **Einbinden in README:** `![Beschreibung](docs/04-prototype/screenshots/datei.png)` + 1–2 Sätze Erklärung darunter
